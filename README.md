# LuntikMusic

Простой и стильный музыкальный плеер для Android на Kotlin + Jetpack Compose + Media3 ExoPlayer.

## Функции
- Сканирование локальной музыки через MediaStore
- Воспроизведение с ExoPlayer
- Базовые контролы: play/pause, next/prev
- Material 3 UI

## Сборка
Используется GitHub Actions для автоматической сборки APK и создания релиза.

Скачать APK можно в Releases.
